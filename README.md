# TtR Map Builder

Локальный редактор игровых полей для Windows x64. Города, отдельные вагоны, подложка, сохранение проектов и экспорт для печати. Интерфейс на русском языке.

## Запуск

Откройте **TtR Map Builder.exe** в этой папке. Установка, Node.js и интернет для работы не нужны. Первый запуск может занять несколько секунд: portable-приложение распаковывает встроенный runtime во временную папку.

Начальное поле — **785 × 525 мм**, вагон — **26 × 9 мм**, город — **10 мм**. Проект открывается пустым. Для знакомства загрузите `examples/Пример карты.ttrmap.json` через кнопку **Открыть**.

## Редактирование

- Слева выберите **Город** или **Вагон** и нажмите на поле. Можно добавить несколько объектов подряд. **Esc** возвращает инструмент выделения.
- Инструментом **Выделение** нажмите на объект и перетащите его. Справа можно задать точные X/Y; начало координат — левый верхний угол поля, X направлен вправо, Y вниз.
- Вагон вращается за круглую ручку над выделением. **Shift** задаёт шаг 15°. Можно ввести угол 0–360° справа; 360° соответствует 0°.
- Название города необязательно. Введите его справа, затем нажмите Enter или выйдите из поля ввода. Подпись можно перетащить или задать её смещение; она следует за городом.
- Размеры справа применяются ко **всем** вагонам и городам. Положение и угол не меняются. Указанные размеры включают обводку.
- Цвет новых вагонов выбирается в разделе **Вагоны**. Цвет уже созданного — в разделе **Выбран вагон**. Палитра: серый, белый, чёрный, розовый, зелёный, синий, красный, жёлтый, оранжевый.
- Числа принимают запятую или точку. Изменения применяются через Enter или при выходе из поля ввода. Некорректное значение возвращается к предыдущему.
- Изменение размеров поля не удаляет объекты за его границами. Они остаются доступны в рабочей области, но не входят в экспорт.

Колёсико приближает поле относительно курсора. **Пробел + перетаскивание** или средняя кнопка мыши перемещают рабочую область. Кнопка с четырьмя углами внизу справа показывает поле целиком. Экранный процент масштаба — условный относительно 96 DPI, он не калибрует физический размер на мониторе.

## Подложка

В нижнем разделе правой панели нажмите **Загрузить PNG / JPEG**. Картинка впишется в поле без изменения пропорций. Она сохраняется внутри проекта.

Для перемещения нажмите **Переместить подложку**, перетащите изображение и завершите режим той же кнопкой. Доступны точные X/Y, непрозрачность, видимость и масштаб относительно вписывания в текущее поле. Кнопка **Вписать** восстанавливает положение и размер по центру. Изменение размеров поля само по себе не меняет геометрию подложки.

Поддерживаются изображения до 75 МБ и 100 мегапикселей. Скрытая подложка не попадает в экспорт. В окне экспорта также можно исключить видимую подложку.

## Сохранение и экспорт

**Сохранить** записывает `.ttrmap.json`. Это редактируемый проект, переносимый одним файлом, включая картинку. **Сохранить как** создаёт отдельную копию. Перед закрытием или заменой несохранённого проекта приложение предлагает сохранить изменения, отказаться от них или отменить действие. Автосохранения нет.

**Экспорт** сохраняет всё поле независимо от масштаба и смещения экрана:

- **SVG** содержит физические размеры в миллиметрах, векторные фигуры и текст. Удобен для типографии и дальнейшей работы в векторных редакторах. Подложка остаётся встроенной растровой картинкой.
- **PNG** поддерживает 96, 150 и 300 DPI. По умолчанию выбраны 300 DPI; для поля 785 × 525 мм результат имеет 9272 × 6201 пиксель. DPI записывается в метаданные PNG. Лимит — 16 384 пикселя по каждой стороне и 100 мегапикселей суммарно.

В файлах нет панели инструментов, выделения и ручек поворота. Фон поля белый. При печати задавайте **фактический размер / 100%**, отключая автоматическое вписывание в страницу. Текст SVG использует Arial с запасным sans-serif; шрифты в SVG не встраиваются.

SVG/PNG предназначены для вывода. Для продолжения редактирования открывайте JSON-проект. Автоматического соединения городов и импорта произвольного SVG нет.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| V / C / W | Выделение / город / вагон |
| Ctrl+N / Ctrl+O | Новый проект / открыть |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D | Дублировать выделенный объект со смещением 5 мм |
| Delete | Удалить выделенный объект |
| Esc | Выделение, выход из режима подложки |
| Пробел + мышь | Переместить рабочую область |
| Shift + вращение | Поворот с шагом 15° |

История хранит 100 действий текущего проекта. Одно перетаскивание — одно действие. История не записывается в файл.

## Исходники и разработка

Требуется Node.js 22.12+ и npm. Зависимости зафиксированы в `package-lock.json`.

```powershell
npm ci
npm run dev
```

Проверка и сборка:

```powershell
npm test
npm run build
npm run test:e2e
npm run build:exe
npm run test:e2e:portable
```

`build:exe` создаёт portable EXE в `release` и копирует его в корень проекта. Иконки уже включены; при необходимости их можно пересоздать командой `node scripts/make-assets.mjs`. `npm start` запускает последнюю сборку без dev-сервера. Сборка не подписывается сертификатом издателя.

Стек: Electron, React, TypeScript, Vite, electron-builder. В `src` находятся модель, история, SVG/PNG-экспорт и интерфейс. В `electron` — файловые операции и изолированный preload-мост. Файлы записываются через временный файл с последующей заменой.

`npm run test:e2e` открывает отдельное окно приложения, выполняет полный сценарий и сохраняет результаты в `test-results`. Системные диалоги в автоматическом тесте подменяются ответами; остальные операции выполняются через интерфейс, а файловые операции — реальным основным процессом Electron.

`npm run test:e2e:portable` повторяет этот сценарий на готовом EXE без Vite-сервера. Тестовый драйвер подключается к временным локальным отладочным портам; при обычном запуске они не открываются. Результат последней проверки — `test-results/portable/smoke-report.json`.

Формат для внешних генераторов описан в [docs/PROJECT_FORMAT.md](docs/PROJECT_FORMAT.md).
