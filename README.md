# TtR Map Builder

Локальный редактор игровых полей для Windows x64, версия **1.2.10**. Города, вагоны, маршруты, подложка, сохранение проектов и экспорт для печати. Интерфейс на русском языке.

## Запуск

Откройте **TtR Map Builder.exe** в этой папке. Установка, Node.js и интернет для работы не нужны. Первый запуск может занять несколько секунд: portable-приложение распаковывает встроенный runtime во временную папку.

Начальное поле — **785 × 525 мм**, вагон — **26 × 9 мм**, город — **10 мм**. Проект открывается пустым. Для знакомства загрузите `examples/Пример карты.ttrmap.json` через кнопку **Открыть**.

## Редактирование

Вверху правой панели всегда видны счётчики городов, всех добавленных вагонов и завершённых маршрутов. Ниже отдельно указано число незавершённых маршрутов. Каждый параллельный маршрут считается отдельно; скрытие соединительных линий не меняет счётчик. Значения обновляются при добавлении, удалении, отмене действий и открытии проекта. Прокрутка настроек не скрывает счётчики.

- Слева выберите **Город** или **Вагон** и нажмите на поле. Можно добавить несколько объектов подряд. **Esc** возвращает инструмент выделения.
- В разделе **Новый город** выберите белый кружок или одно из десяти оформлений — Абрикос, Янтарь, Мандарин, Лазурь, Деним, Сапфир, Фисташка, Мята, Эвкалипт и Изумруд. Чтобы изменить уже поставленный кружок, выделите город и выберите образец в разделе **Выбран город**. Оформление каждого города сохраняется в проекте и видно при экспорте в SVG и PNG.
- Инструментом **Выделение** нажмите на объект и перетащите его. Справа можно задать точные X/Y; начало координат — левый верхний угол поля, X направлен вправо, Y вниз.
- Вагон вращается за круглую ручку над выделением. **Shift** задаёт шаг 15°. Можно ввести угол 0–360° справа; 360° соответствует 0°.
- После добавления города курсор сразу появляется в поле названия. Введите название, затем нажмите Enter или выйдите из поля ввода. Подпись можно перетащить или задать её смещение; она следует за городом.
- В разделе **Города** задайте **Общий размер шрифта городов** в миллиметрах (по умолчанию 3,5). Во время ввода все названия на поле сразу меняют размер. Нажмите Enter или выйдите из поля, чтобы принять значение. Этот кегль применяется и к городам, добавленным позже.
- Размеры справа применяются ко **всем** вагонам и городам. Положение и угол не меняются. Указанные размеры включают обводку.
- С инструментом **Вагон** выберите тип и цвет в разделе **Новый вагон**, затем щёлкните по полю. Для изменения существующего вагона включите **Выделение** и щёлкните по нему. Вверху панели появится раздел **Выбран вагон**. Смена типа или цвета сразу видна на поле и действует только на выбранный вагон, в том числе внутри маршрута.
- Локомотив всегда серый, со значком паровоза. Тоннель обозначен силуэтом двух гор с арочным проёмом. На чёрном вагоне знак светлый, на остальных цветах — тёмный. Обычные вагоны и тоннели поддерживают все девять цветов. Новые маршруты по дуге и параллельные ряды создаются из обычных вагонов.
- Выделите локомотив и нажмите **Развернуть значок** в правой панели, чтобы паровоз смотрел к противоположному торцу. Повторное нажатие возвращает исходное направление. Направление сохраняется в проекте и в экспорте SVG и PNG.
- Числа принимают запятую или точку. Изменения применяются через Enter или при выходе из поля ввода. Некорректное значение возвращается к предыдущему.
- Изменение размеров поля не удаляет объекты за его границами. Они остаются доступны в рабочей области, но не входят в экспорт.

Колёсико приближает поле относительно курсора. **Пробел + перетаскивание** или средняя кнопка мыши перемещают рабочую область. Кнопка с четырьмя углами внизу справа показывает поле целиком. Экранный процент масштаба — условный относительно 96 DPI, он не калибрует физический размер на мониторе.

## Подложка

В нижнем разделе правой панели нажмите **Загрузить PNG / JPEG**. Картинка впишется в поле без изменения пропорций. Она сохраняется внутри проекта.

Для перемещения нажмите **Переместить подложку**, перетащите изображение и завершите режим той же кнопкой. Доступны точные X/Y, непрозрачность, видимость и масштаб относительно вписывания в текущее поле. Кнопка **Вписать** восстанавливает положение и размер по центру. Изменение размеров поля само по себе не меняет геометрию подложки.

Поддерживаются изображения до 75 МБ и 100 мегапикселей. Скрытая подложка не попадает в экспорт. В окне экспорта также можно исключить видимую подложку.

## Маршруты

Между каждой парой разных городов можно создать до **двух завершённых маршрутов**, содержащих хотя бы один вагон. Один вагон принадлежит только одной цепочке. Начните с `examples/Маршруты.ttrmap.json`: в нём два параллельных маршрута по три вагона.

Точка крепления на окружности города рассчитывается автоматически. При перемещении, повороте или изменении размеров объектов линии следуют за ними. Остальные вагоны при этом сохраняют положение. Незавершённые цепочки сохраняются в проекте.

**Создание по дуге:** выберите инструмент **Маршрут** (R). Укажите два города щелчками на поле или в списках справа, количество и цвет вагонов. Перетаскивайте оранжевую управляющую точку для изгиба цепочки. Затем нажмите **Создать маршрут**. Промежутки вдоль дуги равномерные, не менее 2 мм. Если вагоны не помещаются или пересекаются, измените число или изгиб. После создания вагоны редактируются по отдельности; вспомогательная дуга исчезает.

**Параллельная копия:** выделите вагон завершённого маршрута и нажмите **Создать параллельный** в его свойствах. Задайте сторону, зазор между рядами (по умолчанию 4 мм) и цвет. Проверьте предварительное расположение и нажмите **Создать маршрут**. Эта команда доступна, когда между городами пока только один завершённый маршрут. Размеры и положение исходных вагонов сохраняются.

**Свойства и разрыв связей:** при выделении вагона справа показаны его маршрут, число вагонов и конечные города. Можно перекрасить всю цепочку или выключить **Показывать соединения**; скрытие применяется и к SVG/PNG. Для разрыва щёлкните по линии и нажмите Delete либо **Удалить выбранную связь**. **Разобрать маршрут** снимает все связи, сохраняя вагоны. При удалении вагона или города остающиеся части становятся незавершёнными цепочками. Обычное Ctrl+D копирует только объект, без связей.

Создание маршрута по дуге отменяется одним Ctrl+Z. При разделении видимость наследуют обе части.

## Сохранение и экспорт

**Сохранить** записывает `.ttrmap.json`. Это редактируемый проект, переносимый одним файлом, включая картинку. **Сохранить как** создаёт отдельную копию. Перед закрытием или заменой несохранённого проекта приложение предлагает сохранить изменения, отказаться от них или отменить действие. Автосохранения нет.

**Экспорт** сохраняет всё поле независимо от масштаба и смещения экрана:

- **SVG** содержит физические размеры в миллиметрах, векторные фигуры и текст. Удобен для типографии и дальнейшей работы в векторных редакторах. Подложка остаётся встроенной растровой картинкой.
- **PNG** поддерживает 96, 150 и 300 DPI. По умолчанию выбраны 300 DPI; для поля 785 × 525 мм результат имеет 9272 × 6201 пиксель. DPI записывается в метаданные PNG. Лимит — 16 384 пикселя по каждой стороне и 100 мегапикселей суммарно.

В файлах нет панели инструментов, выделения и ручек поворота. Фон поля белый. При печати задавайте **фактический размер / 100%**, отключая автоматическое вписывание в страницу. Названия городов оформлены полужирной Georgia цвета сепии с кремовым ореолом. SVG хранит редактируемый текст и использует системную Georgia. Если шрифт недоступен, программа просмотра подставляет шрифт с засечками. PNG сохраняет отрисованные буквы.

SVG/PNG предназначены для вывода. Для продолжения редактирования открывайте JSON-проект. Импорт произвольного SVG не поддерживается. Версия 1.1 читает старые проекты версии 1; при сохранении записывается формат версии 2 с маршрутами. Старое приложение версии 1.0 новый формат не откроет.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| V / C / W | Выделение / город / вагон |
| R | Инструмент маршрутов |
| Ctrl+N / Ctrl+O | Новый проект / открыть |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D | Дублировать выделенный объект со смещением 5 мм |
| Delete | Удалить выделенный объект |
| Esc | Выделение, выход из режима подложки |
| Пробел + мышь | Переместить рабочую область |
| Shift + вращение | Поворот с шагом 15° |

История хранит 100 действий текущего проекта. Одно перетаскивание — одно действие. История не записывается в файл.

## Исходники и разработка

Требуется Node.js 22.12+ и npm. Зависимости зафиксированы в `package-lock.json`.

```powershell
npm ci
npm run dev
```

Проверка и сборка:

```powershell
npm test
npm run build
npm run test:e2e
npm run test:routes
npm run build:exe
npm run test:e2e:portable
npm run test:routes:portable
```

`build:exe` создаёт portable EXE в `release` и копирует его в корень проекта. Иконки уже включены; при необходимости их можно пересоздать командой `node scripts/make-assets.mjs`. `npm start` запускает последнюю сборку без dev-сервера. Сборка не подписывается сертификатом издателя.

Стек: Electron, React, TypeScript, Vite, electron-builder. В `src` находятся модель, история, SVG/PNG-экспорт и интерфейс. В `electron` — файловые операции и изолированный preload-мост. Файлы записываются через временный файл с последующей заменой.

`npm run test:e2e` открывает отдельное окно приложения, выполняет полный сценарий и сохраняет результаты в `test-results`. Системные диалоги в автоматическом тесте подменяются ответами; остальные операции выполняются через интерфейс, а файловые операции — реальным основным процессом Electron.

`npm run test:e2e:portable` повторяет этот сценарий на готовом EXE без Vite-сервера. Тестовый драйвер подключается к временным локальным отладочным портам; при обычном запуске они не открываются. Результат последней проверки — `test-results/portable/smoke-report.json`.

`test:routes` и `test:routes:portable` дополнительно проверяют создание маршрутов по дуге, ограничение двух маршрутов, незавершённые цепочки, скрытие линий, параллельную копию и экспорт. Отчёты находятся в `test-results/routes` и `test-results/routes-portable`.

Формат для внешних генераторов описан в [docs/PROJECT_FORMAT.md](docs/PROJECT_FORMAT.md).
