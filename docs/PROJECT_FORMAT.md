# Формат проекта `.ttrmap.json`, версия 2

UTF-8 JSON. Файл можно сформировать любой программой, затем открыть в редакторе через **Открыть**. Все перечисленные поля обязательны; если подложки нет, передавайте `null`. Дополнительные неизвестные поля при загрузке отбрасываются.

```json
{
  "format": "ttr-map",
  "version": 2,
  "board": { "width": 785, "height": 525 },
  "sizes": { "wagonLength": 26, "wagonWidth": 9, "cityDiameter": 10, "cityLabelFontSize": 3.5 },
  "objects": [
    {
      "id": "city-a", "type": "city", "x": 100, "y": 150,
      "name": "Первый город", "labelOffset": { "x": 8, "y": -7 }
    },
    {
      "id": "wagon-a", "type": "wagon", "x": 135, "y": 150,
      "angle": 0, "color": "gray"
    }
  ],
  "background": null,
  "routes": [
    {
      "id": "route-a",
      "startCityId": "city-a",
      "endCityId": null,
      "wagons": [{ "wagonId": "wagon-a", "entry": "minus" }],
      "showConnections": true
    }
  ]
}
```

## Геометрия и объекты

- Единица геометрии — **миллиметр**. Числа JSON используют точку. Все числа конечные, размеры строго положительные.
- `board.width` — горизонтальная длина поля; `board.height` — вертикальная ширина.
- `sizes.wagonLength`, `sizes.wagonWidth` и `sizes.cityDiameter` задают общие внешние габариты фигур вместе с обводкой.
- `x`, `y` объекта — координаты его **центра**. Начало — левый верхний угол; X вправо, Y вниз. Отрицательные координаты и координаты за пределами поля допустимы.
- `id` — уникальная непустая строка до 128 символов. UUID необязателен. Допускается до 20 000 объектов.
- `city.name` — строка до 120 символов. Пустая строка отключает подпись. `labelOffset` задаёт начало горизонтальной базовой линии подписи относительно центра города.
- `sizes.cityLabelFontSize` задаёт кегль всех названий городов в миллиметрах. Значение должно быть положительным конечным числом. При отсутствии поля редактор использует 3,5 мм. При открытии старой карты с индивидуальными значениями `city.labelFontSize` все подписи получают общий кегль карты. При сохранении записывается только общий размер.
- Необязательное поле `wagon.kind` задаёт вид вагона. Допустимы `regular`, `locomotive` и `tunnel`. При отсутствии поля вагон обычный. Цвет локомотива при чтении приводится к `gray`. При открытии и пересохранении карты в редакторах 1.1.x поле `kind` теряется.
- Необязательное поле `wagon.locomotiveFlipped` хранит направление значка локомотива. При `true` значок зеркально отражается по локальной координате X перед поворотом вагона. При `false` или отсутствии поля значок имеет исходное направление. Параметр применяется только при `kind: "locomotive"`. Редакторы до версии 1.2.4 пропускают это поле при пересохранении проекта.
- `wagon.angle` — градусы по часовой стрелке, вращение вокруг центра. 0° — длинная сторона горизонтальна. При загрузке значение приводится к диапазону `[0, 360)`.
- Города рисуются поверх вагонов; внутри каждого типа сохраняется порядок массива.

Цвета вагонов:

| `color` | Название | Цвет SVG |
| --- | --- | --- |
| `gray` | Серый | `#9ca3af` |
| `white` | Белый | `#ffffff` |
| `black` | Чёрный | `#38393f` |
| `pink` | Розовый | `#e58db5` |
| `green` | Зелёный | `#71b073` |
| `blue` | Синий | `#4186c6` |
| `red` | Красный | `#d84f4f` |
| `yellow` | Жёлтый | `#f3d362` |
| `orange` | Оранжевый | `#e89248` |

## Подложка

Вместо `null` можно передать объект:

```json
{
  "dataUrl": "data:image/png;base64,<полные байты PNG в base64>",
  "name": "Моя карта.png",
  "pixelWidth": 1600,
  "pixelHeight": 1000,
  "x": 0,
  "y": 17.1875,
  "width": 785,
  "height": 490.625,
  "opacity": 1,
  "visible": true
}
```

`pixelWidth`/`pixelHeight` — исходные размеры картинки в пикселях. `x`/`y` здесь обозначают **левый верхний угол**, а `width`/`height` — размеры на поле в миллиметрах. `opacity` находится в `[0, 1]`. При загрузке подложки средствами редактора пропорции сохраняются; в JSON можно явно задать оба размера. Картинка обрезается границами поля при показе и экспорте.

Допустимы только `data:image/png;base64,...` и `data:image/jpeg;base64,...`. Ссылки на внешние файлы, URL и SVG-подложки не поддерживаются. `name` — строка до 255 символов. Редактор проверяет возможность декодирования изображения. Общий JSON-файл ограничен 150 МБ.

## Маршруты

`routes` — массив цепочек. Если связей нет, передавайте `[]`. Каждая цепочка содержит:

- `id`: уникальный среди маршрутов ID длиной 1–128 символов.
- `startCityId`, `endCityId`: ID двух разных городов или `null` для свободного конца. Наличие обоих городов означает завершённый маршрут. Между неупорядоченной парой городов допускается максимум два завершённых маршрута.
- `wagons`: непустой упорядоченный список `{ "wagonId": "…", "entry": "minus" | "plus" }`. `minus` — торец с локальным X = `-wagonLength/2`, `plus` — с X = `+wagonLength/2`. Поворот вагона учитывается при вычислении мировых координат. Выходной торец всегда противоположен входному.
- `showConnections`: видимость всех соединителей цепочки в редакторе и экспорте. Этот флаг не влияет на принадлежность вагонов.

Связи определяются порядком: начальный город → вход первого вагона, выход предыдущего → вход следующего, выход последнего → конечный город. Координаты соединителей не хранятся. К городу линия приходит на внешнюю окружность в направлении его центра от торца вагона.

Вагон может встречаться только один раз во всём массиве маршрутов. Все ссылки должны вести на объекты правильного типа. Изолированный вагон без городов и соседних вагонов хранится только в `objects`. Такая структура исключает ветвления и замкнутые цепочки. Незавершённые цепочки с одним или двумя свободными концами допустимы. Цвета и геометрия вагонов по-прежнему принадлежат объектам.

## Совместимость

Открытие неизвестной версии, неправильных размеров, повторяющихся ID, неизвестных цветов, повреждённого JSON или изображения завершается ошибкой без замены текущего проекта. Поддерживается UTF-8 BOM. Масштаб экрана, выделение и история действий не сохраняются.

Версия приложения 1.1.0 читает форматы 1 и 2. При загрузке версии 1 добавляется пустой `routes`, объекты и подложка сохраняются. Все последующие сохранения используют версию 2. Приложение 1.0 отклоняет её, предотвращая потерю маршрутов. Некорректные ссылки маршрутов, повторное использование вагонов и третий завершённый маршрут между парой городов отклоняются при загрузке.
